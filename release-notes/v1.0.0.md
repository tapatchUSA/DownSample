**DownSample 1.0.0** for Windows 10/11 (x64) · Free for personal use

### What's new

- Initial public release
- GPU hardware encoding via Windows Media Foundation + Direct3D 11 — NVIDIA / AMD / Intel, no FFmpeg
- Resolution downscale (4K to 240p or custom) with aspect-ratio control
- Quality and audio-bitrate presets, including audio-off
- Parallel batch queue with whole-folder + subfolder import
- Single-file preview, keep-or-replace originals, custom name suffix
- GPU / CPU / Both processor modes with multi-GPU support
- Fully offline — no bundled codec, no network, no telemetry
